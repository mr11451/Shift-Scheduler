# パスワード変更画面

## 概要

ログイン中のメンバが発行したワンタイムURLから、新しいパスワードを設定する画面です。

## URL

- `/password-reset/:staffId/:token`
- `staffId` は対象メンバID、`token` はランダムなワンタイムアクセス用トークンです。

## 遷移元

- `/member` の「自分のパスワードを変更」ボタン
- SMTP送信時は登録メールのURL
- SMTP未設定または送信失敗時は、会員画面に表示するダイアログのURL

## 入力項目

- 確認コード: メールまたは会員画面ダイアログで取得する6桁コード
- 新しいパスワード: 8文字以上
- 新しいパスワード（確認）: 新しいパスワードと一致が必要

## 処理

1. メンバが会員画面から再設定情報を発行する。
2. サーバーはメンバIDとランダムトークンを含むURL、および確認コードを作成する。
3. SMTP送信可能なら登録メールアドレスへ送信する。送信不可時はURLと確認コードを会員画面で表示する。
4. 利用者はURLを開き、確認コードと新しいパスワードを入力する。
5. サーバーはトークン・コード・有効期限を検証し、パスワードを更新してトークンを使用済みにする。

## 制約

- URLと確認コードの有効期限は発行から1時間
- 以前の未使用トークンは新しい発行時に無効化される
- トークンと確認コードはハッシュのみを保存する
- パスワード変更後、変更日時以前に発行されたJWTは無効となる

## 結果

- 成功時はログイン画面へのリンクを表示する
- 新しいパスワードで再ログインするまで、既存のログイン状態は継続できない
- URL、確認コード、有効期限切れ、または使用済みの場合はエラーを表示する
