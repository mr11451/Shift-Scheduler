# 管理者画面

## 概要

本画面では、シフト運用に必要なマスタ情報を管理します。
スタッフ編集画面・シフト編集画面で使用する定義は、すべて本画面で設定します。

## URL

- `/admin`
- アクセス条件: ログイン済みかつ `CHIEF` または `MASTER`
- 未ログイン時: `/`（ログイン画面）へ遷移
- `MEMBER` でアクセスした場合: `/` へ遷移

## 目的

- スタッフの新規登録・更新・無効化
- 資格項目（オプション）の文言・内容の管理
- シフト記号・種類・時間帯の管理
- メンバー間カレンダー閲覧機能（申請/許可）の提供有無を管理
- メンバー初回ログイン通知機能の提供有無を管理

## 画面構成

- スタッフ管理タブ
- 資格管理タブ
- シフト種類管理タブ
- システム設定タブ

## 管理者画面からの遷移先

- スタッフ登録・編集画面（管理者）
- 資格管理画面（管理者）
- シフト種類管理画面（管理者）
- スタッフ個別カレンダー画面

## システム設定（オプション）

### メンバー間カレンダー閲覧機能

- 設定項目名: メンバー間カレンダー閲覧機能
- 設定値: 有効 / 無効
- 初期値: 無効（推奨）
- 有効時の挙動
	- メンバが同一グループ内の他メンバへ閲覧申請を送信可能
	- 申請先メンバが許可した場合のみ閲覧可能
	- 許可済み相手のカレンダーへ遷移するUIを表示
- 無効時の挙動
	- 申請・許可・遷移UIを非表示
	- 既存の申請/許可状態は参照不可（データは保持してもよい）

### メンバー初回ログイン通知

- 設定項目名: メンバー初回ログイン通知
- 設定値: 有効 / 無効
- 初期値: 無効（推奨）
- 付帯設定: 初回ログインアクセスURL（ベースURL）
- 有効時の挙動
	- メンバ新規登録時に、登録メールアドレスへ初回ログイン情報を送信
	- 送信内容はアクセスURL、ログインコード、ログインパスワード
	- 送信失敗時は失敗履歴を保持し、管理者が再送できる
- 無効時の挙動
	- メンバ新規登録時の自動送信を行わない
	- 必要時は管理者の明示操作でのみ送信可能

## スタッフ管理

### 機能

- 新規登録
- 編集
- 無効化（退職・休職などで一覧対象から除外）
- 検索（登録番号、氏名、担当）
- 個別カレンダー表示

### 管理項目

- 登録番号（必須、重複不可）
- 氏名（必須）
- 担当（必須）
- グループ（メンバ/チーフで必須）
- 資格（オプション、複数可）
- 権限レベル（必須: メンバ / チーフ / マスタ）
- 有効/無効

### ルール

- 登録番号は一意
- 無効化したスタッフは、スタッフ編集画面の初期一覧から除外
- シフト実績が存在するスタッフは物理削除しない

## 権限レベル定義

- メンバ
: スタッフ個別カレンダー画面のみ参照可能

- チーフ
: メンバ権限 + 同一グループのメンバに対するシフト確認・調整（ただし管理者画面はアクセス不可）

- マスタ
: 全画面の管理権限（スタッフ、資格、シフト種類、権限設定）

## 資格管理

### 機能

- 資格の新規追加
- 資格名の変更
- 資格の無効化
- 表示順の変更

### 管理項目

- 資格コード（内部管理用）
- 資格名（表示名）
- 説明（任意）
- 有効/無効
- 表示順

### 反映先

- スタッフ編集画面の資格項目
- スタッフ登録・編集フォームの資格選択候補

## シフト種類管理

### 機能

- シフト種類の新規追加
- 記号・名称・時間帯の編集
- 有効/無効の切り替え
- 表示順の変更

### 管理項目

- シフト記号（必須、重複不可。例: A, P, -）
- シフト名称（必須。例: 早番、遅番、休み）
- 開始時刻（休み以外は必須）
- 終了時刻（休み以外は必須）
- 有効/無効
- 表示順

### バリデーション

- 記号は一意
- 同一記号で有効データを複数持てない
- 開始時刻 < 終了時刻
- 休み種別は時間帯未設定を許可

### 反映先

- シフト編集画面の記号入力候補
- シフト編集画面の時間帯定義（表示・チェック）

## 他画面との関係

- スタッフ編集画面
: 本画面で管理されたスタッフ情報（登録番号・氏名・担当・資格）を表示

- シフト編集画面
: 本画面で管理されたシフト記号・種類・時間帯定義を使用

## 権限

- マスタ: 管理者画面の全更新操作が可能
- チーフ: 管理者画面へのアクセス不可
- メンバ: 管理者画面へのアクセス不可（スタッフ個別カレンダー画面のみ参照可）

## 監査ログ追加項目（推奨）

- システム設定変更前/変更後（メンバー間カレンダー閲覧機能）
- システム設定変更前/変更後（メンバー初回ログイン通知、アクセスURL）
- 変更者
- 変更日時

## 監査ログ（推奨）

- 変更者
- 変更日時
- 変更対象（スタッフ/資格/シフト種類）
- 変更前後の値
