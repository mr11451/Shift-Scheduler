# スタッフ編集画面

## 概要

本画面では、スタッフ情報の検索・一覧表示を行います。
スタッフ登録機能は管理者画面で実施します。

## URL

- 独立URLなし（現行ルーティング未割当）

## 検索エリア

- 番号: スタッフ番号で絞り込み
- 氏名: スタッフ氏名で絞り込み
- 担当: 担当業務で絞り込み
- グループ: 所属グループで絞り込み
- 検索ボタン: 入力条件で一覧を検索

## 一覧表示項目

- 番号
- 氏名
- 担当
- グループ
- 資格（オプション）
- 権限レベル（メンバー / チーフ / マスター）
- 操作（カレンダー）

## 個別カレンダー遷移

- スタッフ一覧の各行に [カレンダー] ボタンを配置する
- 押下したスタッフの「スタッフ個別カレンダー画面」へ遷移する

## 資格項目の仕様

- 資格欄は固定値ではなくカスタム入力可能とする
- 管理者は資格の文言・内容を任意に登録、編集、変更できる
- 変更した資格内容はスタッフ一覧および登録・編集画面に反映する

## 一覧表示のスクロール仕様

- スタッフ件数が画面に表示しきれない場合、一覧領域を上下スクロール可能とする
- 検索エリアは固定表示し、一覧のみ縦スクロールする

## 権限

- メンバー: 本画面はアクセス不可（スタッフ個別カレンダー画面のみ参照可）
- チーフ: 参照可能
- マスター: 参照可能
