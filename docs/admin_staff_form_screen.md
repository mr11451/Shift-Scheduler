# スタッフ登録・編集画面（管理者）

## 概要

管理者がスタッフの新規登録および既存スタッフ情報の編集を行う画面です。
管理者画面の「スタッフ管理」タブから遷移します。

## URL

- 独立URLなし
- 表示位置: `/admin` 内の「スタッフ管理」タブ

## 遷移元

- 管理者画面 > スタッフ管理タブ > [新規登録]
- 管理者画面 > スタッフ管理タブ > 一覧行の [編集]

## 入力項目

- 登録番号（自動割り付け）
- 氏名（必須）
- メールアドレス（メンバ登録時は必須）
- 電話番号（オプション）
- 担当（必須）
- グループ（メンバ/チーフで必須、プルダウン選択）
- 資格（オプション、複数選択可）
- 権限レベル（必須: メンバ / チーフ / マスタ）
- 状態（有効/無効）

## 操作ボタン

- 保存
- キャンセル

## 初回ログイン通知（オプション）

- 管理者設定「メンバー初回ログイン通知」が有効な場合のみ利用する
- メンバを新規登録して保存したタイミングで、登録メールアドレスに以下を送信する
	- アクセスURL
	- ログインコード
	- ログインパスワード（初期）
- 送信失敗時は登録自体は成功とし、通知ステータスを失敗で保持する
- 管理者は再送操作を実行できる

## バリデーション

- 登録番号は自動割り付け（編集不可）
- 氏名は必須
- メンバ選択時はメールアドレス必須
- 電話番号は数字とハイフンのみ、未入力可
- 担当は必須
- メンバ/チーフ選択時はグループ必須（プルダウンから選択）
- 資格は未選択可
- 権限レベルは必須

## 保存後の動作

- 正常時: スタッフ管理タブへ戻り、最新状態を一覧に反映
- 異常時: エラーメッセージを表示し、入力内容を保持

## 権限

- メンバ: アクセス不可
- チーフ: アクセス不可
- マスタ: 参照・登録・編集可能
